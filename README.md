# 🚚 BakkieForHire-v1

A web application for booking refrigerated bakkies (pickup trucks) for hire. Built with Angular and hosted on Firebase.

**🔗 Live Demo**: [https://bakkieforhire-v1.web.app/](https://bakkieforhire-v1.web.app/)
